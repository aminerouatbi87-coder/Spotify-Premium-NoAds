## 🚀 Installation Rapide

### Sur votre Mac

```bash
# 1. Cloner le repo
git clone https://github.com/aminerouatbi87-coder/Spotify-Premium-NoAds.git
cd Spotify-Premium-NoAds

# 2. Installer les dépendances
npm install

# 3. Lancer le serveur
npm start
```

### Ouvrir l'app

Allez dans votre navigateur :
```
http://localhost:3002
```

## 📊 API Endpoints

```
GET  /api/songs              # Toutes les chansons
GET  /api/songs/search       # Rechercher
GET  /api/songs/genre/:genre # Par genre
GET  /api/playlists          # Toutes les playlists
GET  /api/playlists/:id      # Détails playlist
GET  /api/top-songs          # Top 10 chansons
GET  /api/health             # Statut du serveur
```
